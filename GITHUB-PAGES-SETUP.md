# PANDATEC GitHub Pages setup

1. Copy the contents of this folder into the `pandatec-website` repository.
2. Commit the files to the `main` branch.
3. Open the repository on GitHub and select **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**, then select **Save**.
6. Wait for GitHub to finish publishing, then open the website link shown in the Pages settings.

This is a static display version. It does not include WordPress administration, product importing, quote storage or WordPress form processing. Connect the company domain after the GitHub Pages link has been tested.
